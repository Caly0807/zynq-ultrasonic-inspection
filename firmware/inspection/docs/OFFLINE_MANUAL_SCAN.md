# 脱机视觉定位与手动面扫

## 目标流程

不连接电脑和网线，QSPI 上电后由 ARM Linux 启动相机、采集服务与 LVGL 小屏。
上电默认停止采集、关闭发射和运动；进入页面或完成视觉标定不启动发射。

1. 固定相机和 80×80×30 mm 工件，在探头轴线处安装清晰可见的唯一红色定位标记。
2. 小屏选择“视觉面扫”→“选取四角”，在冻结图像中按左上、右上、右下、左下选择工件表面四角。
3. 确认相机和工件不再移动后按“确认固定”。移动相机、移动工件或相机重新枚举后应重标定。
4. 接好真实模拟链路、耦合探头，明确允许发射后，5 秒内按两次“真实波形”。只有该操作会请求真实 ADC 采集。
5. 确认探头垂直、允许连续视觉定位录入，5 秒内按两次“开始面扫”。缓慢移动探头并在各网格内短暂停稳。
6. 小屏显示探头位置、已采样格、未扫格、有效诊断格及疑似反射格。按“结束二维”停止采集并查看二维图；“三维点图”查看有可信深度的反射点。

## 数据与显示原则

- 灰色：未采样；绿色：有效采样且无阈值指示；红色：疑似反射；黄色：未标定；紫色：无效。白圈是视觉估计的探头位置。
- 5 mm 网格为采样单元，不代表整个网格或声束覆盖区域已经经过合格检验；未扫区域始终未知。
- 录入需要同一相机标定、唯一有效红标记、至少三张不同图像、至少 350 ms 停稳、同格位置漂移不超过 1 mm，以及图像/ADC 单调时钟之差不超过 200 ms。
- 摄像头辅助程序的出队时间不是传感器曝光时间，未实现相机与超声硬件同步；坐标和精度标为未经物理验证的估计值。
- 定位丢失、相机掉线、移动过快、时序不匹配不生成新的位置点；相机标定改变或本地真实采集租约失效后，必须明确重新开始面扫。
- 小屏真实采集保活来自板端 LVGL，不依赖电脑网页。停止、退出进程或租约过期后不得自动恢复发射。
- 内部缺陷结论来自真实回波，不从相机照片猜孔。三维图是校准后的反射指示点，不是孔形、孔径、孔高或 CT 重建。

## 当前边界

本轮新增的是本地操作和连续位置关联路径，软件测试及原生编译不等于实板扫描验收。
声学零点、声速、安静基线门、诊断门与阈值仍须使用真实完整块/有孔块验证；未完成时不显示可信缺陷深度。
本轮不自动批准任何标定。当前声学参数通过板端配置导入，尚未提供完整的小屏声学校准向导。
当前扫描会话与视觉标定位于 RAM，断电会丢失；本轮未格式化或写入 SD，也未实现标定的持久恢复。
本版本结束后保留本次结果；5 秒内按两次“新工件”停止采集并创建新会话，旧会话保留在本次上电的 RAM 中，断电仍会丢失。
