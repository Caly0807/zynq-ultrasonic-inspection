# 小屏声学设置与完整块参考检查

## 先分清三个界面

- “参数设置”控制波形的显示量程、显示阈值等界面参数，不代表修改了 ARM 诊断门限。
- “声学设置”修改板端诊断的门区、基线、门限和声学参考参数。
- “视觉面扫”负责四角标定、探头辅助定位、真实波形启停和采样地图。

页面的打开、参数编辑、相机标定和网络连接均不会自动启动发射。真实发射必须由操作者明确允许，并在“真实波形”或 LIVE 按钮上二次确认。关闭物理 HV 不代表软件可以自行测试真实采集。

## 参数草案

顶部选择“声学设置”，下拉选择参数，按 +/- 修改后点击“更新当前项”。星号表示该项尚未发出更新请求。参数包括：

| 参数 | 含义 |
| --- | --- |
| 缺陷门起点/终点 | 相对数字触发的时间窗，单位 us |
| 底波门起点/终点 | 相对同一触发的底波搜索窗 |
| 安静门起点/终点 | 已采集窗口内，经过人工确认没有回波/振铃的基线窗 |
| 缺陷/底波阈值 | 相对基线的绝对幅度，单位 ADC 码，不是百分比 |
| 参考声速 | 操作者输入的材料纵波声速，单位 m/s |
| 手动零点 | 电子与声路延迟的时间修正，单位 us |
| 参考块厚度 | 完整参考块厚度，单位 mm；不会自动改动被检工件的尺寸档案 |

实时采集当前没有预触发样本，必须显式配置安静基线门。草案初值 100~110 us **不是已经验证安静的结论**，不会在开机时自动应用。门区必须落在本次实际采集范围内、起点小于终点，基线不能与诊断门重叠。

按两次“应用未标定”（间隔不超过 5 秒），会停止当前采集，等正在处理的一帧结束后应用草案，同时撤销有效标定。它不会重新启动采集。需要操作者再明确开启真实波形。

显示门区不应故意避开待测浅孔，也不能单纯提高阈值使完整块“变绿”。如果完整块在待检深度的时间窗已有强信号，应先查耦合、发射泄漏、探头振铃、接收恢复等物理原因，或另行验证有依据的抑制方法。

## 完整块参考

1. 使用已知无孔的完整块，在同一探头、耦合方式与增益下停稳并保持垂直入射。核对厚度、声速和各门区。
2. 明确开启本地真实波形。参考只能来自小屏当前持有的 LIVE 采集，不能用电脑会话、历史 CSV 或演示帧代替。
3. 5 秒内按两次“采完整块参考”，确认确实是完整块、垂直耦合且参数已核对。
4. 请求后取 8 张不同的新鲜帧；限时 5 秒，单帧龄不超过 300 ms。失去本地采集所有权、增益变化、波形不稳定、削顶、基线噪声过大、缺少底波或完整块缺陷门超限都会拒绝。
5. “8 帧检查通过”仅表示 **READY/待人工审核**，不会自动校准。需要人工同时观察实际前段信号，确认未把串扰、振铃或错误底波当成参考。
6. 零点建议 = 8 帧门内底波峰时间中位数 − `2000 × 参考厚度 / 声速`。这是基于操作者输入厚度与声速的单厚度零点估计，不是独立测得材料声速或证实孔深。
7. 参考通过后 60 秒内，5 秒内按两次“审核并应用”。程序核对当前仍为同一采集所有者与增益，再停采、等待在途帧结束并应用参考。它不会自动重启。
8. 重新明确开启真实波形，再用已知缺陷工件与无孔位置对照验证。参考增益一旦改变，诊断会变为无效，不能沿用旧参考。

已经存在扫描点时禁止更换实际诊断配置，避免同一地图混用标定；先导出并结束旧任务，再新建空工件。扫描进行中也不允许进入修改流程。

## 深度与检查边界

深度计算为 `d_mm = (t_us − zero_us) × c_mps / 2000`。门区仍以原始触发为基准，批准零点后 **不会偷偷移动门区**。例如零点为 1 us、声速为 5900 m/s 时，22 mm 反射应在约 8.46 us；原缺陷门终点 8.00 us 会漏掉该理论时刻。应按实际参考重新核对门区，并与底波门留出间隔，而不是机械套用开机初值。

- 基线、门区、零点、增益和耦合尚未通过真实试块验证时，不能承诺检出全部缺陷或报告可信孔深。
- “无阈值指示”不是工件无缺陷合格证。无有效底波、无耦合或超量程应保持无效，不得显示无缺陷。
- 三维是有依据的反射位置/深度指示点，不是孔形、孔径或孔高重建。
- 视觉只估计探头位置，不透视内部孔。需人工核对红标记与真实声束入射点的偏差及正背面方向。
- 参数草案、参考原始帧、审核报告、视觉标定和扫描数据当前仅在板端 RAM；断电丢失。持久保存需要通过上位机导出，SD 持久化尚未实现。
- 参考目录保存 8 帧历史 CSV 和 `review.json`；重放后必须标为 RECORDED，不能继续当作当前 LIVE。

## 常见拒绝提示

| 提示 | 应做的检查 |
| --- | --- |
| 请先在视觉页开启真实波形 | 必须人工明确启动本地采集；页面不会替你启动 |
| 门区或零点不合理 | 核对时间窗顺序、采样范围、基线与诊断门间隔 |
| 完整块缺陷门超限 | 不能批准；检查前段干扰，不靠隐藏浅层或抬阈值过关 |
| 安静门不安静 | 对照原始波形重选实际安静窗口 |
| 底波不足 | 检查耦合、连接、增益和底波门；缺底波不等于无孔 |
| 参考不稳定/过期/增益改变 | 固定探头与配置后重新采参考，不自动重试发射 |
| 请先新建空工件 | 先导出旧任务，再新建；不能混用不同标定 |

上述是软件状态和操作规则；源码测试、镜像构建与只读运行检查不能代替真实触控、耦合、缺陷检出和冷启动验收。
